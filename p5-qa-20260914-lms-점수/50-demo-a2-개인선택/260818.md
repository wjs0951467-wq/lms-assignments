# 2026-08-18 TIL 프로그래밍 기초와 Python 개발 환경 이해

## 오늘 배운 것

오늘은 Python 문법을 배우기 전에 **프로그래밍이 어떤 방식으로 동작하는지**와 실제로 코드를 실행하기 위한 환경을 배웠다.

프로그래밍의 기본 흐름은

`입력 → 처리 → 출력`

이며, 컴퓨터에게 원하는 작업을 논리적으로 명령하는 것이 프로그래밍이다.

Python의 기본 개념으로는 다음을 배웠다.

- **변수**: 값을 저장
- **조건문**: 조건에 따라 실행
- **반복문**: 같은 작업을 반복
- **리스트**: 여러 값을 순서대로 저장
- **딕셔너리**: `키 : 값` 형태로 저장
- **함수**: 특정 작업을 묶어 재사용

코드를 작성할 때는 바로 실행하기보다 **먼저 결과를 예상하고 실행한 뒤 실제 결과와 비교하는 과정**이 중요하다.

```
코드 읽기
→ 결과 예상
→ 실행
→ 결과 비교
→ 문제 발견
→ 수정
→ 다시 실행
````

오류가 발생했을 때도 바로 답을 찾기보다 오류 메시지를 확인하고 원인을 생각하는 것이 중요하다.

또한 Python 코드를 실행하기 위해서는 Python과 개발 도구가 필요하다.

* **Python**: 코드를 실행
* **VS Code**: 코드를 작성하고 관리
* **Python Extension**: VS Code에서 Python을 편리하게 사용
* **Python 인터프리터**: Python 코드를 실제로 실행

Python 파일은 `.py` 확장자를 사용하며 터미널에서 다음과 같이 실행할 수 있다.

```
python 파일이름.py
```

## AI를 활용한 학습

AI가 코드를 대신 작성해줄 수 있지만, 코드를 이해하지 못한 채 그대로 사용하는 것은 좋지 않다.

AI는 정답을 대신 받는 도구보다 **코드를 이해하고 문제를 해결할 수 있도록 도와주는 튜터**처럼 활용하는 것이 중요하다.

특히 다음을 확인하는 습관을 만들어야 한다.

* 이 코드는 무엇을 하는가?
* 왜 이렇게 작성했는가?
* 실행 결과가 예상과 같은가?
* 오류가 발생하면 원인은 무엇인가?

## 오늘 느낀 점

코딩은 문법을 외우는 것보다 **코드의 흐름을 이해하고 직접 실행하면서 결과를 확인하는 과정**이 중요하다는 것을 알게 되었다.

또한 AI 시대에는 코드를 직접 작성하는 능력뿐만 아니라 **AI가 만든 코드를 이해하고 검증하는 능력**이 중요하다고 느꼈다.
